【日本語】
----------------------------------------------------------------

■ 短い説明文（132文字以内）

X (x.com) の投稿メディアを保存。保存済みメディアのマーク表示と重複保存防止にも対応。ファイル名もカスタマイズ可能。


■ 詳細説明文

X (x.com / Twitter) のタイムラインに表示される画像や動画をダウンロードできる拡張機能です。

【主な機能】
- 画像をクリックするとオリジナル画像をオーバーレイ表示
- 複数メディアの投稿はプレビュー・一括ダウンロードに対応
- j/k キーでオーバーレイ内のメディアをスムーズに切り替え
- 各メディアにホバーするだけで表示されるダウンロードボタン
- ファイル名パターンを自由にカスタマイズ（例: {username}_{tweetId}_{index}）
- 保存フォーマットを選択（オリジナル / JPEG / PNG）
- 保存済みメディアにマークを表示
- 保存済みメディアの重複ダウンロードを防止するオプション
- 表示言語を切り替え可能（日本語 / English）
- 動画・GIF 相当の投稿メディア保存に対応（取得できる直MP4 URLが対象）

【キーボードショートカット】
- Alt+S         ホバー中のメディアを保存
- Alt+Shift+S   投稿の全メディアを保存
- A             フォーカス中の投稿メディアをプレビュー表示
- D             プレビュー中のメディアを保存
- J             次のメディアへ（オーバーレイ表示中）
- K             前のメディアへ（オーバーレイ表示中）
- Esc           プレビューを閉じる

このツールは X Corp. および Twitter, Inc. とは無関係の独立した非公式ツールです。

【English】
----------------------------------------------------------------

■ Short description (up to 132 characters)

Save media from X posts, mark already-saved items, and optionally prevent duplicate downloads.


■ Detailed description

Download images and videos from X (x.com / Twitter) timeline posts with ease.

Features:
- Click any post image to preview it full-screen at original quality
- Preview and batch-download multiple media items
- Navigate between media items using j/k keys in the overlay
- Hover download button appears directly on each media item
- Fully customizable filename pattern (e.g. {username}_{tweetId}_{index})
- Choose save format: original / JPEG / PNG
- Mark media that has already been saved
- Optionally skip duplicate downloads for already-saved media
- Switch display language between Japanese and English
- Supports video/GIF-like post media when a direct MP4 URL is available

Keyboard Shortcuts:
- Alt+S           Save hovered media
- Alt+Shift+S     Save all media in focused post
- A               Preview media in focused post
- D               Save previewed media
- J               Next media (while overlay is open)
- K               Previous media (while overlay is open)
- Esc             Close preview

This is an independent, unofficial tool not affiliated with, endorsed by, or sponsored by X Corp. or Twitter, Inc.
